# Odin Recipes

A basic recipe website built as part of [The Odin Project](https://www.theodinproject.com/) Foundations course.

## About

This project is a simple HTML website containing a collection of recipes. It demonstrates the basics of:

- HTML boilerplate
- Headings and paragraphs
- Links and navigation
- Images
- Ordered and unordered lists
- Organizing files and directories

## Recipes

The website currently includes:

- Butter Chicken
- Chicken Biryani
- Paneer Tikka
